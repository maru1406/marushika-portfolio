# Marushika Kalyan Portfolio

Next.js + Tailwind CSS portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Add profile photo

Place your professional photo at:

`public/profile.jpg`

Then replace the placeholder in `app/page.tsx` with an image using `/profile.jpg`.

## Resume

The current resume is included as `public/MARUSHIKA_RESUME.pdf` for the download button.

## Before deployment

Update the LinkedIn URL, Tableau dashboard URL, and any project links in `app/page.tsx`.


## Kuchipudi background image
The Kuchipudi photograph is already included as `public/dance-bg.jpeg`.
The section uses a real `<img>` element so the photograph reliably appears behind the content.
